04 · Music

A soundtrack that plays along

Today Logic Sprint is silent apart from tap clicks. Music should make a run feel like it's building, never get in the way of thinking, and never fight the player's own music or the ads.

What plays where

  • Menus (Play, Ranks, Profile): one calm theme, low and steady.
  • Each game gets its own loop that matches its skill: a driving synth for Rocket Launch, soft arpeggios for Memory Lane, a ticking pulse for Quick Math, a playful bounce for Guess Color, later Angle Sense and Line Split.
  • Loading screen: a short rising sting as the rocket lifts LOGICSPRINT.
  • Moments: a short sting for a new best, a soft drop when the run goes down, a lift on the 3 · 2 · 1 comeback.

It reacts to the run

  • Each loop is made of 2–3 layers (stems) that fade in as the run gets harder: bass first, then drums, then the lead. Same tempo, so it never skips.
  • When a timer runs low, a quiet ticking layer joins.
  • On a miss or "Game over" the music drops to a filtered, quieter version; on revive it comes back up through the countdown.
  • Paused or in the background: music pauses and resumes where it was.

Plays nice

  • Two switches in Settings: Music and Sounds (today's switch becomes Sounds), plus a music volume slider.
  • Your own music wins: if Spotify or Apple Music is already playing, the game's music stays off and only sounds play (iOS "ambient" audio, Android audio focus).
  • Silent switch: on iPhone, the ring/silent switch mutes the game's music, like most games.
  • Ads: music fades out before an ad and back in after; it never plays over an ad.
  • Accessibility: nothing in play depends on hearing it.

How it's built

  • Packages: just_audio (gapless loops, several players at once) and audio_session (ambient mode, ducking, interruptions). Both are widely used; run the vet-third-party checklist before adding.
  • A small MusicDirector service next to AppState: knows the current screen and game, listens to the run (RoundEngine state, question number, timer) and sets layer volumes with short fades.
  • Files: loops as AAC/M4A, 30–60 s each, about 0.5–1 MB per layer; whole soundtrack under about 10 MB so the app stays small.
  • Tests: the director's decisions (which track, which layers, when to fade) are pure Dart and tested with fake time; actual playback is checked by ear on a device.

Where the music comes from

  • Option 1 · Commission a composer for a small set of stems in the Circuit Noir feel. Best fit and fully owned; costs money and a few weeks.
  • Option 2 · Licensed royalty-free tracks that come with stems. Fast and cheap; check the licence allows in-app use without credit screens or per-download fees.
  • Option 3 · AI-generated music. Only from a tool whose terms grant commercial use, and keep the licence on file.
  • Whatever the source, keep the licence files in assets/audio/LICENSES.md. The privacy policy doesn't change; nothing is uploaded.
05 · Decisions

Made, and still yours

Already decided

  • Revive: 5 s offer stays; 3 s get-ready after the ad or heart.
  • Estimation games get 3 strikes; right-or-wrong games keep one miss.
  • Angle Sense windows ±8° → ±5° (Hard ±9° → ±6°); ±3° is a Sharp bonus.
  • Line Split is one ramping mode; game 6.
  • True or False moved to ideas; both new games open flat → upright → crossed.
  • "Sprint Score", shown as "Top X%" only (no number), hidden below the top 25%.
  • Profile: no wordmark, 2×3 grid with Sprint Score, one "Share stats" button at the bottom.
  • Top 10: ‹ game › switcher with dots; difficulty row never moves.
  • Instagram links: copied for the user to paste into a link sticker; Snapchat can attach the link itself (phase 2).
  • State management stays on Provider.

Still open

  • Line Split input: answer on lift (fast) or place-then-Lock (fewer slips)?
  • Sprint Score strength: shrinkage k = 2 (one game worth at most 66) or softer?
  • Direct share buttons: worth a Meta app ID and Snap review?
  • Music source: commission a composer, license royalty-free stems, or use an AI tool with commercial rights?
  • Music by default: on at first launch (at a low volume) or off until switched on?
06 · Order that matters

Dependencies

Merge first

feat/revive-countdown changes RoundEngine (the new resuming state). Every new game builds on it, so it lands before Angle Sense and Line Split ship.

Backend before app

Each new game name must be allowed in game_bests.game_type before the app ships, or those scores are silently lost. Use one dated migration file per change; Sprint Score's view + RPC also deploy first.

Branches

feat/profile-share also touches leaderboard.dart and the Profile tab; merge it after the countdown branch and run make check on the result before any release build.

Right now: the 1.0.4 work is uncommitted on feat/revive-countdown. Commit it (or split it into a few commits) before starting anything else, so nothing gets lost or mixed with the next feature.
