01 · The sentence ladder

Six kinds of sentence

Each rung adds one new idea from logic and keeps everything before it. Scenes grow too, from 4 shapes to 10. Shapes vary in three ways: kind (circle, square, triangle), colour (red, blue, yellow, green) and size (big, small).

Facts

Q1–8 · 4–5 shapes
  • There are exactly 3 circles.count
  • There is a red square.exists

All · Some · No

Q9–16 · 5–6 shapes
  • All circles are red.for all
  • Some squares are big.there is at least one
  • No triangle is blue.none

NOT

Q17–25 · 6–7 shapes
  • Not every square is yellow.not all
  • Some circles are not small.some … not

AND · OR

Q26–35 · 6–8 shapes
  • Every square is red or big.or
  • Some circle is blue and small.and

IF · ONLY

Q36–50 · 7–9 shapes
  • If a shape is red, it is a circle.if … then
  • Only squares are green.only (the one people flip)

Everything, faster

Q51+ · 8–10 shapes
  • Any sentence above, chosen at random.the timer keeps tightening
02 · Fair for humans

Two buttons, so guessing must not work

With only TRUE and FALSE, a guess is right half the time. And because one miss ends the run, even small error rates cut runs short. So the game needs three things: sentences that are about half true, enough time to actually read, and a timer that scales with what's on screen.

Accuracy per question → how far you get

Right per questionMedian run20 in a row
99%6982%

97%2354%

50% (guessing)10%

Untimed, adults get simple "all / some" sentences about a small picture right nearly every time. Errors come from rushing and from tricky words ("only", "not every"). So the timer is where difficulty lives, and it must never be shorter than reading speed.

A timer that respects reading

time = (1.2 s + 0.28 s × words + 0.12 s × shapes) × factor 5 words, 4 shapes → 3.1 s × factor 9 words, 7 shapes → 4.6 s × factor 12 words, 10 shapes → 5.8 s × factor Medium factor 1.6 at Q26, falling to 1.15 by Q60 Hard factor 1.3 at Q1, falling to 0.95 by Q60 never under 2.5 s

0.28 s a word is a slow silent-reading pace (about 210 words a minute) so non-native readers are covered. 0.12 s a shape covers scanning the picture. A long, tricky sentence about a big scene always gets more time than a short one.

Balanced: the generator decides "true" or "false" first (50/50), then builds a scene and sentence that come out that way, so there's no pattern to exploit.

04 · Screen design

Question, right, wrong

Same layout family as Guess Color: game bar, a picture card, then the input. The sentence sits right above the two buttons so the eye goes picture → sentence → thumb. Answer buttons carry ✓ and ✕ as well as colour.

05 · Under the hood

Every sentence is checked by code

The risky part of this game is a sentence that's ambiguous or wrongly marked. Players will screenshot it. So sentences are data, not text: each one is a small logic object that can say what it means, check itself against the scene, and list the shapes that prove the answer.

The model

Shape { kind, colour, size } Property kind = circle | colour = red | size = big Sentence sealed class: Count(P, n) Exists(P, Q) All(P, Q) Some(P, Q) No(P, Q) NotAll(P, Q) SomeNot(P, Q) AllOr(P, Q, R) SomeAnd(P, Q, R) If(P, Q) Only(P, Q) sentence.text → "All circles are red." sentence.eval(sc) → true / false sentence.proof(sc) → shapes to light up sentence.why(sc) → "All 3 circles are red."

Rules that keep it fair

  • No empty "all": "All circles are red" is only asked when there's at least one circle. Logic says it's true with no circles; players feel it's false.
  • "Some" means at least one, and the rules screen says so once.
  • Grammar from templates, never string-glued: "a circle" vs "circles", "red shape" vs "circle".
  • Shapes are easy to tell apart: big is 1.6× small and kinds differ in outline. Red and green are close in lightness today, so before building, check the four colours in a colour-blind simulator and adjust one, or add a small pattern per colour.
  • 50/50 truth: pick the answer first, then regenerate until the scene matches (in practice under 20 tries).
  • Tests: every sentence type has a truth-table test, and 10,000 random seeds check that the text, the answer and the proof always agree.

07 · Playbook

From plan to store

Lock the sentences

0.5 day
  • Agree on the six rungs and the exact wording of each template.
  • Decide the name (see open questions).

Logic core with tests

1.5 days
  • sentence.dart and generator.dart first, with truth-table and 10,000-seed tests.
  • Print 200 random sentences with their scenes and read them all. Fix anything that sounds odd.

Engine and board

2 days
  • Engine on RoundEngine (get-ready countdown and revive come free).
  • Board with proof highlight and the reveal line.

Wire in and migrate

0.5 day
  • Game list, home grid (3×2), ranks, Supabase migration.

Playtest the timer

2 days
  • Five or more people, including a non-native English reader. Log answer times per sentence type.
  • Target: a typical player reaches Q20–25 on Medium; no sentence type gets more than 10% wrong untimed (if it does, reword it).

Store and release

1 day
  • Screenshot, listing line ("New: True or False. Can you out-think the sentence?"), ship with or right after Angle Sense.
08 · Decide before building

Open questions

Name"True or False" matches trueorfalse.dev and says exactly what you do. It also means the game shares its name with the studio; if that's confusing in the store, "Truth Check" or "Fact Check" are fallbacks.
LanguagesSentences are English-only at first. Templates are built so other languages can be added later without touching the logic.
Show the reason?The reveal line ("All 3 circles are red.") teaches the logic but slows the run by about a second. Show it on every question, or only on a wrong answer?
Sharp bonusA "Quick" bonus (+5) for answering within the first third of the timer, like Angle Sense's Sharp, or keep scoring plain?
