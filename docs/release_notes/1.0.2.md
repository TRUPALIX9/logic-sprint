## What's new in 1.0.2

**iPhone**
- LogicSprint's first App Store release

**Leaderboard**
- Delete your leaderboard data from Settings: your name and scores are removed from the server
- Long-press a name on Ranks to report it; names reported by several players are hidden
- Names with offensive words are refused
- Scores no real run could reach no longer count toward the boards

**Fixes**
- On iPhone, watching a rewarded ad to the end now always gives the revive or heart (the reward can arrive after the ad closes)

**Removed**
- "Donate a view" (Settings → Support and the Hearts sheet); hearts still come from the ad after each run
